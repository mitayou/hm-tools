## 特征

- 💡 优化资产处理
- 🚀 渲染进程的快速 HMR
- 🔥 主进程和预加载脚本的热重载
- 🔌 易于调试
- 🔒 编译为 v8 字节码以保护源代码

## 项目设置

### 安装

```bash
$ npm install
```

### 开发运行

```bash
$ npm run dev
```

### 构建项目

```bash
# 适用于 Windows
$ npm run build:win

# 适用于 macOS
$ npm run build:mac

# 适用于 Linux
$ npm run build:linux
```
